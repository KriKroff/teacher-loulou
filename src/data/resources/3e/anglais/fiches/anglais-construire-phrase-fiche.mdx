# 🧱 Construire sa phrase en anglais

*Grammaire — to, -ing, want somebody to, his / her, génitif*

> **Le but :** maîtriser les « petits mots » qui font la différence : *to*, *in*, *-ing*, *him*, *his / her*, *'s*.

---

<Glossaire>
<GlossaireItem term="Base verbale">Le verbe **« tout nu »** : sans *to*, sans *-s*, sans *-ing*. Ex. : *hack* → pirater, *go* → aller.</GlossaireItem>
<GlossaireItem term="V-ING">La base verbale + **-ING** : *hacking, being, having*. ⚠️ Ce n'est **pas** un participe passé (celui de *hack*, c'est *hacked*).</GlossaireItem>
<GlossaireItem term="Génitif">La forme **'s** pour dire « la chose de quelqu'un » : *the Dean's computer* → l'ordinateur du doyen.</GlossaireItem>
<GlossaireItem term="Phrasal verb">Verbe + petit mot qui forment **un bloc** : *put up with* → supporter.</GlossaireItem>
</Glossaire>

---

<Section title="TO + base verbale ou préposition + -ING ?" color="purple" emoji="🔀" index={1}>

Quand deux verbes se suivent, regarde le **petit mot** juste devant le 2ᵉ verbe.

<Formule>
🅰️ verbe + **TO** + base verbale → *managed **to hack***

🅱️ verbe + **PRÉPOSITION** + V-**ING** → *succeeded **in hacking***
</Formule>

| 🅰️ TO + base verbale | 🅱️ Préposition + V-ING |
|---|---|
| *manage to* → réussir à | *succeed in* → réussir à |
| *want to* → vouloir | *dream about* → rêver de |
| *try to* → essayer de | *care about* → se soucier de |
| *need to* → avoir besoin de | *fail at* → échouer à |
| *decide to* → décider de | *without* → sans |
| *hope to* → espérer | *before / after* → avant de / après |
| *fail to* → ne pas réussir à | |

<Retenir title="La règle">
**When a verb follows a preposition, -ING is the only solution.**

→ Après une préposition, **-ING est la seule solution**.

*Ferris doesn't care about Cameron **being** sick.* → Ferris se moque que Cameron soit malade.
</Retenir>

<Erreur title="Jamais TO + -ING !">
❌ *He succeeds **to hacking** the computer.*

✅ *He succeeded **in hacking** the computer.* → Il a réussi à pirater l'ordinateur.

✅ *He managed **to hack** the computer.* → Il a réussi à pirater l'ordinateur.

**TO** → base verbale. **IN** → **-ING**. Si tu mets *to*, aucune raison de mettre *-ing*.
</Erreur>

<Astuce title="« A réussi » → prétérit">
Action terminée → le **1ᵉʳ verbe** au prétérit : *managed*, *succeeded*.

Le 2ᵉ verbe ne bouge pas : *managed to **hack*** (❌ *to hacked*).
</Astuce>

</Section>

<Section title="« Vouloir que » : WANT + quelqu'un + TO" color="blue" emoji="🙏" index={2}>

En anglais, **pas de *that*** et **pas de subjonctif** après *want*.

<Formule>
**want(s)** / **would like** + QUELQU'UN + **TO** + base verbale
</Formule>

<Exemple>
*Jeanie **wants her parents to realise** that Ferris is a liar.*
→ Jeanie veut que ses parents réalisent que Ferris est un menteur.

*He **would like his friends to remember** him.*
→ Il aimerait que ses amis se souviennent de lui.
</Exemple>

Si « quelqu'un » est un pronom : **me, him, her, us, them** (jamais *he, she, they*).

| Sujet | Après *want* | Exemple |
|---|---|---|
| he | **him** | *Ferris wants **him** to come over.* → Ferris veut qu'il vienne. |
| she | **her** | *They want **her** to go to school.* → Ils veulent qu'elle aille à l'école. |
| they | **them** | *Rooney wants **them** to listen.* → Rooney veut qu'ils écoutent. |

<Erreur title="Les 3 pièges">
❌ *Jeanie wants **that** her parents realise…* → jamais *that*.

❌ *Jeanie wants her parents realise…* → il manque ***to***.

❌ *Ferris wants **he** to come.* → ✅ *wants **him** to come*.
</Erreur>

</Section>

<Section title="HIS ou HER ? Regarde le possesseur" color="green" emoji="🔑" index={3}>

Le possessif dépend de **celui à qui est la chose**, pas de la chose.

| Possesseur | Possessif | Exemple |
|---|---|---|
| un garçon (Ferris) | **his** = à lui | *Ferris → **his** parents* (ses parents) |
| une fille (Jeanie) | **her** = à elle | *Jeanie → **her** parents* (ses parents) |
| plusieurs personnes | **their** = à eux | *Ferris and Jeanie → **their** parents* |

<Astuce title="La question magique : « à qui ? »">
« ses parents » → les parents **de qui** ? → de Jeanie → une fille → ***her** parents*.
</Astuce>

</Section>

<Section title="Le génitif : the Dean's computer" color="orange" emoji="🏷️" index={4}>

« La chose de quelqu'un » → **possesseur + 's + chose**.

| Possesseur | On ajoute | Exemple |
|---|---|---|
| **un seul** | **'s**, toujours, même si le mot finit déjà par *s* | *the **Dean's** computer* → l'ordinateur du doyen · ***Ferris's** school* → l'école de Ferris |
| **plusieurs** (pluriel en *-s*) | **'** seul | *her **parents'** behaviour* → le comportement de ses parents |

<Erreur>
❌ *the computer of the Dean* → ✅ *the **Dean's** computer*

❌ *her parents's behaviour* → ✅ *her **parents'** behaviour*
</Erreur>

</Section>

---

<Section title="En bref" color="cyan" emoji="⚡" index={5}>

**🎯 Le but (« pour », « pour que »)**

- ***(in order) to*** + base verbale : *Ferris lies **to skip** class.* → Ferris ment pour sécher les cours.
- ***so that*** + sujet + ***can / could*** : *Ferris lies **so that he can** skip class.* → … pour pouvoir sécher.

**🧩 Les phrasal verbs : on apprend le bloc entier**

| 🇬🇧 | 🇫🇷 |
|---|---|
| *put up **with*** | supporter, tolérer |
| *get out **of*** | sortir de |
| *come **over*** | venir (chez quelqu'un) |
| *pick somebody **up*** | passer prendre quelqu'un |

❌ *Rooney can't put up this.* → ✅ *Rooney can't put up **with** this.* (Rooney ne supporte pas ça.)

**👉 C'est lui qui… :** *Cameron is **the one who** needs a day off.* → C'est Cameron qui a besoin d'un jour de repos.

</Section>

---

<Retenir title="✅ Ma checklist">
1. Après **TO** → base verbale. Après une **préposition** → **-ING**. Jamais *to + -ing*.
2. « vouloir que » → ***want* + quelqu'un + to** (*him / her / them*, pas de *that*).
3. ***his*** ou ***her*** → regarde le **possesseur**.
4. Un possesseur → **'s** (*Ferris's*). Pluriel en -s → **'** (*parents'*).
</Retenir>
